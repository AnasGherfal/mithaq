# Mithaq | ميثاق

**تعارف موثّق للزواج الجاد**

This repository contains the production-oriented technical foundation for
Mithaq, an Arabic-first, private marriage-introduction network for serious adult
Libyans in Libya and the diaspora.

## Current milestone

**Milestone 3 — Verified waitlist and phone OTP**

The application now includes the bilingual public trust site plus the Stage A
waitlist flow: 18+ and serious-marriage intent gates, phone OTP authentication,
a structured questionnaire, required and optional consent records, private
referrals, registration status, questionnaire editing/resume, communications
withdrawal, deletion requests, RLS-protected Supabase tables, and cross-user
isolation tests.

Identity/liveness verification, member profiles, matching, photographs,
messaging, family participation, administration, payments, and private
introductions are still outside this milestone. A phone-verified waitlist user
must not be described as identity verified.

## Technical baseline

- Node.js 24 LTS
- pnpm 11.22.0
- Next.js 16 App Router and React 19
- TypeScript strict mode
- Tailwind CSS 4 and shadcn/ui-compatible primitives
- `next-intl` with always-prefixed `/ar` and `/en` routes
- Supabase SSR clients, local Supabase CLI, Auth, Postgres RLS, and pgTAP
- Vitest, Testing Library, Playwright, and axe
- Serwist PWA integration for Turbopack

## Prerequisites

Install:

1. Node.js 24 LTS.
2. pnpm 11 (`corepack enable` is recommended).
3. Docker Desktop or a compatible Docker runtime for local Supabase.
4. Git.

## Setup

```bash
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env.local
pnpm icons:generate
```

Use only local or development values in `.env.local`. Never commit that file.
The SMS values in `.env.example` are non-secret local placeholders used to let
Supabase Auth exercise deterministic test OTPs; they are not production Twilio
credentials.

Start local Supabase:

```bash
pnpm db:start
pnpm exec supabase status
```

Copy the local publishable/anon key reported by `supabase status` into
`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in `.env.local`, then run:

```bash
pnpm dev
```

Open `http://localhost:3000`. The root URL deterministically redirects to `/ar`;
English is available at `/en`.

For local phone-auth testing, `supabase/config.toml` defines deterministic OTPs
for reserved test numbers. These values are for automated/local testing only and
must never be reused as a production authentication mechanism.

## Verification commands

```bash
pnpm icons:generate
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:db
pnpm exec playwright install --with-deps chromium
pnpm test:e2e
```

`pnpm check` runs formatting, linting, type checking, unit tests, and a
production build in that order. Run `pnpm build` before `pnpm test:e2e`, because
the E2E suite starts the production server.

The CI database job additionally starts local Supabase, runs the pgTAP suite,
builds against the live local stack, and executes the deterministic phone OTP →
questionnaire → consent → success → status → edit/resume Playwright journey.

Stop local Supabase when finished:

```bash
pnpm db:stop
```

## PWA privacy boundary

The service worker precaches only build assets and the bilingual offline
fallback. It defines no runtime cache for APIs or Supabase requests and must
never cache authenticated responses, private questionnaire data, profile
information, or protected media. Authenticated milestones require continued
cache-policy review so this boundary does not regress.

The mark in `public/icons` is an original, provisional architectural-threshold
symbol generated by `scripts/generate-pwa-icons.mjs`. It is not a final brand
identity.

## Database types

After reviewed schema changes, regenerate local Supabase TypeScript definitions
with:

```bash
pnpm db:types
```

Keep application data-access types synchronized with reviewed migrations before
expanding Stage A data access.
